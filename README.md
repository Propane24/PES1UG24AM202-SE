## Project Overview

The **Micro-Lending & Peer Credit Risk Assessor** is a peer-to-peer microfinance platform that helps lenders make informed decisions by assessing borrower credit risk, generating EMI repayment schedules, supporting loan funding, and providing automated default warnings.

## Lab 1 – Requirements Engineering & UML Use-Case Modelling

### Objective

To analyze the given problem statement and prepare software requirements along with UML use-case modelling.

### Deliverables

- Functional Requirements (FR-001 to FR-005)
- Non-Functional Requirements (NFR-001 and NFR-002)
- UML Use-Case Diagram
- Use-Case Flow Specification
- Acceptance Criteria and Rationale for each requirement

### Key Features

- Credit risk assessment using borrower financial indicators
- EMI repayment schedule generation
- Peer lender loan marketplace
- Loan funding workflow
- Automated default warning notifications
- Secure handling of borrower financial data

## Lab 2 – Agile Backlog Creation & Sprint Simulation in Jira

### Objective

To apply Agile Scrum principles by converting the Lab 1 requirements into a structured Jira project with epics, user stories, backlog prioritization, sprint planning, and progress tracking.

### Deliverables

- Scrum Project (Company-managed)
- Product Backlog
- Epics
- User Stories
- Story Point Estimation
- Backlog Prioritization
- Two Mock Sprints
- Burndown Chart
- Sprint Reflection

### Epics Created

1. Loan Application & Risk Assessment
2. Repayment Management
3. Peer Lending Marketplace
4. Default Monitoring & Compliance
5. Security & Data Protection

### Sprint Overview

#### Sprint 1

Focused on building the core lending workflow.

- Loan application
- Credit risk assessment
- EMI schedule generation
- Loan browsing
- Loan funding

#### Sprint 2

Focused on repayment and platform reliability.

- Loan repayment
- Default warnings
- Risk audit logs
- Secure transactions
- Data protection

### Agile Concepts Practiced

- Scrum methodology
- Backlog management
- User story creation
- Story point estimation (Fibonacci)
- Sprint planning
- Kanban workflow (To Do → In Progress → Done)
- Burndown chart analysis
